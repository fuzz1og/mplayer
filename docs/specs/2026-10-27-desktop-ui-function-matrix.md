## 证据层级声明

截图由 **Chromium + electronAPI stub** 渲染真实 DOM 得到，不是真实 Electron 进程。
本机 `node_modules/electron/dist` 缺失且下载受网络限制，故无法做 Electron 层验收。
这一层级能覆盖：布局塌陷、CSS 覆盖错误、组件渲染崩溃、路由可达性。
不能覆盖：真实 IPC 时序、原生窗口行为、播放链路。
