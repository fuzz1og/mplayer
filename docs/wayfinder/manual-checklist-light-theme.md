## 需 dev build（expo run:android）验证项——Expo Go 不可测

- 通知展示/更新 + 分类按钮（上一首/播放暂停/下一首）——对应 #93：启动后首次请求通知权限（Android 13+ 弹 `POST_NOTIFICATIONS` 授权框），允许后通知栏出现媒体迷你播放区（封面/歌名/歌手 + 三按钮）
- 锁屏控制（`setActiveForLockScreen`）：标题/艺术家/封面/按钮
- 后台播放 >3 分钟不中断
- 通知点击打开播放器
- 权限拒绝路径：拒绝授权后播放仍正常（无崩溃），通知不出现属预期
