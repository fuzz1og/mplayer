# 真机回归手测清单（wayfinder #85）

> Map #79 的资产。设备：OnePlus PKB110（Android 15）/ Expo Go。基于 #83 research 的 38 项验证清单转为可勾验项。
> 勾验方式：逐项操作 → 对照预期 → 通过打 ✓ / 失败记 ✗ + 现象。
> **Expo Go 限制**：通知/锁屏控制被显式禁用（isExpoGo guard）——该项标注「需 dev build」的跳过，其余必须测。

## 1. 播放（核心，音频重构重点）

| # | 操作步骤 | 预期结果 | 结果 |
|---|---------|---------|------|
| 1.1 | 播放一首歌，立即快速连点下一首 5+ 次 | 无两首同时出声、无爆音/卡顿、最终停在最后点的那首 | ☐ |
| 1.2 | 播放中切到队列里任意一首，再切回 | 每次切换都干净停旧声、起新声 | ☐ |
| 1.3 | 播放（有直链的）一首歌，中途断网再恢复 | 不崩；恢复后要么继续要么按「失败重试→跳下一首」提示 | ☐ |
| 1.4 | 播放一首收藏的旧歌（URL 可能过期） | 先尝试 → 失败 → 「将使用新 URL 重试」日志 → 恢复播放（不卡死） | ☐ |
| 1.5 | 歌曲播完自动切下一首；三种播放模式各测（单曲/列表/随机） | 单曲循环：同一首重播；列表循环：到末尾回第一首；随机：不按顺序 | ☐ |
| 1.6 | 拖动进度条到任意位置 | 播放位置跟随，不跳回 | ☐ |
| 1.7 | 暂停 → 切后台 → 恢复（<3 分钟） | 恢复后位置不变；重新打开 App 继续播放 | ☐ |
| 1.8 | **重启 App** 后播放同一首最近播放的歌（命中 `songUrl:` 缓存） | 秒起（无重新解析等待）；日志可见「开始播放」 | ☐ |
| 1.9 | 全屏播放器：播放/暂停/上下一首/进度/歌词滚动/点击歌词跳转 | 全部可用，歌词与播放位置同步 | ☐ |
| 1.10 | 播放失败场景：找一首探测标记「无效」的歌播放 | 日志提示失败，自动跳下一首；队列只有它一首时提示并暂停 | ☐ |
| 1.11 | 来电/其他 App 播放音频打断 | 当前歌暂停（doNotMix），回来可恢复 | ☐ |
| 1.12 | 后台播放 >3 分钟（Expo Go） | 预期会被系统停止（已知限制，确认日志有说明即可，不报 bug） | ☐ |

- 后台播放 >3 分钟不中断
- 通知点击打开播放器
