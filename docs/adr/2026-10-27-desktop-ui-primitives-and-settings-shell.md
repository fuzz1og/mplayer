# ADR: 桌面端自建 UI 原语、设置全屏视图与「选中不用品牌蓝」

- 状态：**已接受**（2026-10-27，grilling 两轮收敛；实施票 #679–#690，单 PR #691）
- 日期：2026-10-27
- 关联：#678（父票）· `docs/specs/2026-10-27-desktop-ui-redesign.md`（实施规格）· `docs/specs/ui-refactor-guide.md` §11 · ADR `2026-08-23-desktop-dark-mode-tokens.md`（语义 token 与三态主题，本决策沿用其架构）

## 背景

桌面端 UI 由两套语言拼成：Ant Design 6 提供 13 个组件（56 处引用：message 18、Modal 11、Button 7、Tag 5、Switch 4、Typography 3、Input 2，Progress/Alert/Checkbox/Table 各 1），其余由 170 个 renderer 文件里的 1102 处内联 `style` 与 119 处色值字面量手写。实测代价：

| 指标 | 现值 |
|---|---|
| 主 chunk | 1016 KB（gzip 395 KB），含 cssinjs 运行时、anticon、rc-dialog |
| `node_modules/antd` | 57.5 MB |
| 设计语言 | 2 套（antd token + 自定义 CSS 变量） |
| 内联样式 | 1102 处 |

结构上，设置页同时铺开全局侧栏、设置二级导航、内容区三层，1225 宽窗口下内容只剩约 740；品牌蓝同时用于「选中」与「主操作」，界面上到处是蓝，层级只能靠 1px 描边和卡内套卡表达。

## 决策

### 1. 移除 Ant Design，自建原语（不可逆）

用 11 个自建组件承接全部用法：Button、IconButton、Tag、Input、Switch、Segmented、Progress、Alert、Checkbox、Stepper、Dialog、Toast，外加 3 个布局原语 Group / Section / Row（inset grouped 分组卡）。Toast 取代 message，Dialog 基于原生 `<dialog>` 取代 Modal，唯一一处 Table 改为语义化 GridList。

**为什么不可逆**：删依赖后所有调用点都改写成自建 API，回退等于回滚整个 PR；因此必须一次做对。

**否决的替代**：保留 antd 只做主题桥（上一轮已做过：`ConfigProvider` 接了 `darkAlgorithm` 与 `colorPrimary`，观感没变，两套语言继续并存）；引入第二套组件库（换汤不换药，仍然不可控）。

### 2. 设置改为全屏视图

设置是独立 hash 路由下的全屏壳：进入后隐藏侧栏与播放栏、保留标题栏，左上「‹ 返回」与 ESC 均可退出，**播放不中断**（播放器不卸载，只隐藏）。

**为什么选全屏而非模态或抽屉**：设置需要可深链（`#/settings/cache`）、需要键盘可达、需要在 1024 宽下仍然宽松；模态会限制高度并抢焦点，抽屉解决不了宽度问题。

**代价**：改设置时看不到播放栏。可接受——返回后滚动位置与播放状态都还在。

### 3. 选中态用表面明度差，品牌蓝只给主操作

选中 = `--surface-selected`（暗色 `rgba(255,255,255,.10)`，浅色 `#E9E9EE`）；品牌蓝（`#2F5FD0` / 暗 `#3D7BD9`）只出现在主按钮、焦点环与链接。侧栏不再用左边条 + 蓝底表示选中。

**理由**：SwiftUI 的侧栏与列表选中本来就是「表面差」而不是色相；蓝只留给「现在按下去会发生什么」。

**代价**：需要新增一组表面 token；选中与 hover 只差 0.03–0.04 的明度，弱视用户需要焦点环兜底（焦点环仍是蓝色，且对比度 ≥ 3:1）。

### 4. 门禁一次清账，不留存量白名单

`design-lint` 对桌面端改为严格模式：禁止内联样式（仅允许 `style={{ '--x': value }}` 传自定义属性）、禁止颜色字面量、禁止 `antd` 引入、禁止字号/字重/圆角字面量；只有 token 定义文件豁免，**不设逐项黑名单**。

**否决的替代**：沿用「清一处填一处」的黑名单（现有 `LEGACY_HEX` 空清单就是这种模式的产物——没人回来填，门禁形同虚设）。

## 后果

- 新增维护面：约 1200 行自建原语（含测试），换来主 chunk 与依赖体积下降、单一设计语言；
- 可访问性不再由第三方库兜底：焦点陷阱、ESC、焦点归还、`aria-*` 全部要自己测，测试写在 `src/renderer/__tests__/ui*.test.tsx`；
- 移动端不受影响（下个版本单独跟），但 token 命名与取值保持同源，避免两端再次分叉；
- 门禁严格后，任何新页面若写内联样式会直接红，短期会有摩擦。

## 回退选项

1. 若自建原语出现无法在 1.9.0 修完的可访问性缺陷 → 局部回退到 antd（保留依赖，仅替换问题组件），代价是设计语言再次分裂；
2. 若全屏设置被证明影响高频操作 → 加一个「设置浮层」入口复用同一批 Section 组件（组件本身就是按行组织的，可在模态里复用）；
3. 若「选中不用蓝」在某页确实读不出选中状态 → 该页可加左侧 2px 指示条作为补偿，但不改全局色规则。
