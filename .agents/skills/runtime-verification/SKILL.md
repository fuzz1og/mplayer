# 真机验真

**验真** = 把改动声称的行为，在**真实目标**上跑出来，留下别人能复核的证据。CI 已经证过的（lint / typecheck / 四套测试 / build，见 `scripts/verify.mjs`）不重复证。

没有证据的「已测」和没有原因的「未做」都不算验真。**证据必须声明来自哪个 runtime**——同一句「我验过了」，在 jsdom、Chromium+stub、Expo Go、dev build、真 Electron、打包产物上，证明力完全不同。这个 skill 的每一步都在为这一句话服务。

## 0. 先列命题

从 issue 的验收标准 / spec / PR diff 里抄出「这次要证明什么」，一条一行，**动手之前就写下来**：

| # | 命题（可观察的行为） | 端 | runtime | 证据类型 | 状态 |
|---|---|---|---|---|---|
| 1 | 切到随机模式后队列顺序稳定、当前曲不重复 | 移动 | dev build | logcat 断言 | |
| 2 | 表头拖到视口外时缝为 0 | 桌面 | 真 Electron | CDP 截图 + 偏移量 | |

- **证据类型**按 §3 的强度阶梯先想清楚，别等收尾再从截图堆里找。
- **runtime** 不只是「在哪台设备上」：它决定这条结论算不算数（各 references 的「这一层证不到什么」就是为此而写）。
- 清单是**第 0 步的产物**，收尾只是逐行关闭。实测两次漏项都出在「没有清单、边验边想」的会话里：一次是事后自述「其中两条在模拟器上本来就能验，是我没去做」，一次是被追问「为什么手机端的没验」。

## 1. 选目标

| 目标 | 什么时候 | 读哪份 |
|---|---|---|
| **桌面** Electron | 改动落在 `src/renderer` / `src/main` / preload / IPC 契约 / 托盘 / 打包与更新器 | `references/desktop.md` |
| **移动** Android 真机或模拟器 | 改动落在 `packages/mobile`；或落在 `packages/core` 且影响双端行为 | `references/mobile.md` |

`packages/core` 的改动对两端都是行为改动——只在一端验，结论只覆盖那一端。两端都碰就两端都验。

## 2. 先证明跑的是这份代码（身份锚）

任何取证之前先做这一步：**从正在运行的目标里取回一份产物或状态，在其中认出这次改动的新符号**。跑错源码时后面所有结论作废——实测踩过：设备上装的是旧 APK，日志里的「changed=true」是假成功，最后靠拉回设备 `base.apk` 扫 dex 才把它推翻。

两端各有一条命令与各自的真相源，见 references 的「身份锚」一节。这一条不成立就不要往下走——先把 runtime 换对。

## 3. 逐条取证：证据强度从高到低

1. **可断言的日志**——代码里本来就有的埋点（移动端 `console` 会镜像进 logcat；桌面端主进程 stdout / 渲染层 console）。比截图更省也更硬：能用日志判读的就不截图。
2. **结构化文本**——移动端 `uiautomator dump` 拿带 `text=` / `bounds=` 的节点树；桌面端用 CDP `page.evaluate` 读真实 DOM。**要坐标、要文案断言，先 dump / evaluate 再截图。**
3. **截图**——退居视觉复核。先裁感兴趣区域再读（全屏 PNG 1.5–2.6MB，连读十几张代价很高）；图注写「这张图证明了什么」，不写文件名。

**量化结论要配「真的动了」**：零告警 / 零掉帧单独不成立，必须同时给出「跑到了哪一步」（列表滚到第 N 名、连播到第几首、点了哪个页面）。

## 4. 附到 PR

证据图**不入库**：传 PR 正文或验收评论，`--attach` 之后读回正文验引用。机制、两步法与正文格式的唯一出处是 `docs/agents/git-workflow.md` §5 与 `.github/PULL_REQUEST_TEMPLATE.md`。

## 完成标准

命题清单里**每一行**都以两种状态之一收尾：

- **PASS**——附一条能复核的证据（命令 + 输出，或图 + 图注），且证据确实来自 §1 选定的那个 runtime；
- **未做 + 原因**——一句话说清为什么做不了（没设备 / 需要真人手指 / 改动不触达这一层）。

写完 PR 正文后自查两件事：Evidence 里说清了**证据来自哪一层**（真 Electron / 打包产物 / Chromium+stub / 真机 + 哪个 runtime）；图片引用都是上传后的 `user-attachments` URL，本地路径残留为 0。

**「已附图」而实际没附、或者用「等价环境」而不说清等价到什么程度，都不算完成。**
